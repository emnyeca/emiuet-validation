# Hearthの任意ベンチ接続

> **Historical:** pre-Rev.B検証案の任意interface記録です。現行mandatory validationではありません。

## 目的

HearthをEmiuetの外付け電源にするための仕様ではありません。PWR-01と負荷側の
どちらに問題があるかを比較し、電源条件を変えて再現性を見るための検証接続です。

## 許可する用途

- CORE-01や周辺基板を電流制限付きで単独立ち上げする
- PWR-01と同じ負荷を接続して、電圧降下やノイズを比較する
- 故障したPWR-01を切り離し、負荷側の短絡や過電流を調べる

## 禁止する解釈

- Hearthで動いたためPWR-01を合格とする
- EUB-BUSをRev.Bの必須外部コネクタとする
- Hearthの+3V3とEmiuet側レギュレータ出力を直結する
- USB、PWR-01、Hearthからの給電を逆流対策なしで同時接続する

## 接続前チェック

1. 対象基板の全給電元を列挙する
2. Hearthと対象基板を無通電にする
3. GND、使用レール、許容電圧、最大電流、信号のプルアップ先を記録する
4. 不要な+5V/+3V3/status線を接続しない
5. 最初は電流制限を設定し、対象基板単体の抵抗値を確認する
6. 接続図と結果を測定記録へ添付する

Hearth Rev0自体が未検証の場合、既知の安全なベンチ電源より先に使用しません。
