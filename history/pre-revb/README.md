# Pre-Rev.B Historical Validation

このディレクトリは、内蔵電池、充電、PowerPath、複数USB、PWR/CORE/MAT/ANA/UI/MIDI/INT分割基板、およびG0–G9を前提にした旧検証案の保存場所です。Rev.B current specificationやmandatory gateではありません。

旧資料は設計判断の履歴と再利用可能な観測事項を残すため削除していません。現行判断はリポジトリ直下のREADME、`docs/architecture.md`、`docs/validation-matrix.md`、および製品repo `emnyeca/emiuet` を優先してください。
