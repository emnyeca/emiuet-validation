# MAT-01: 6×13キー行列

2×4ブレッドボードで走査条件を確定した後に製造する、行列専用PCBです。

## 搭載範囲

- 6行×13列、合計78スイッチ
- `STR -> SW -> Diode(A->K) -> FRT` のROW2COLダイオード
- 6本のSTR、13本のFRT、GNDを診断ヘッダへ出す
- 行列の端と中間に導通確認用パッドを置く

## 搭載しないもの

- MCU、電源変換、スライダー、OLED、MIDI出力

## 合格の中心

- 全78キーの位置とMIDIノート対応
- 単押し、複数弦の和音、隣接キー、素早い押離で欠落・ゴーストがない
- GPIO45/46に対応するキーを押した状態でも、製品方針どおり安全に起動する
- 長時間走査で接点状態やイベント順序が破綻しない
